This folder contains raw textual transcripts of chosen Youtube videos.

`golden` refers to 52 videos selected in a previous work led by Prof. Larry Liebovitch.
1 of the 52 videos was unable to be displayed anymore in our current region, so the file `transcripts_golden` only contains raw transcripts of 51 videos.

`add00` is an additional dataset. There are 6 manually assigned classes of videos in this dataset and in total there are 36 videos in this.

The fields are:
`video_id`: Youtube Video ID that uniquely identified a video. Substitute the <video_id> in https://www.youtube.com/watch?v=<video_id> and one can visit the original Youtube video site.
`text`: Raw transcripts.
`class`: Manually assigned classes.
